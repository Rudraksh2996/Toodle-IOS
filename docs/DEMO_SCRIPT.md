# Three-minute walkthrough

Before presenting: enable **Force offline demo mode** in Settings. Leave cloud sync off. Open Command once while online if you want cached map tiles.

1. **0:00–0:25 — Home.** Introduce hyperlocal flood risk across 12 Delhi NCR nodes. Explain that latency and lead-time tiles are product targets.
2. **0:25–0:50 — Command.** Open Command Center. Show map annotations and the priority queue. Switch standard/satellite if tiles are available.
3. **0:50–1:15 — Node detail.** Open Minto Bridge. Expand the sheet to show the rain input, live observations gathered during the session, and weather forecast. Dismiss with Done.
4. **1:15–1:40 — Storm.** Play Storm Sequence. Four stages compress one hour into twelve seconds. KIET Main Gate rises through FRI 0.0625, 0.3825, 0.8415 and 0.9445. Watch queue order and the hazard banner.
5. **1:40–2:05 — Dispatch.** Open the red banner, read the preview, and choose Simulate dispatch. Show the simulated result and cooldown. No SMS is sent.
6. **2:05–2:40 — Capture.** Select a road photo in the simulator, then Analyze image. Offline analysis is explicitly simulated. Explain fresh GPS and live-camera requirements for verified field evidence.
7. **2:40–3:00 — Settings.** Show endpoint configuration, health check, offline toggle and node directory. In offline mode diagnostics explicitly report Offline.

For live integration demonstrations, disable offline mode only after verifying the configured backend and intended SMS recipients. A live dispatch is a deliberate action, never a consequence of playing the simulator.
